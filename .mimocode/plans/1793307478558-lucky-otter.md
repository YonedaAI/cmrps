## Drafter + reviewer resolution

- Drafter = the executing host model (it writes; no lookup needed to write).
  `RESEARCH_DRAFTER_MODEL` names it for swap decisions + reports.
- Family chain: env → host config (`~/.codex/config.toml` model;
  `~/.config/opencode/opencode.jsonc` model) → unknown (claude/mimo expose no model key).
- Unknown family → reviewers AGY+Codex (host-disjoint vendors) + `noSelfReview: true`
  enforced in every prompt. Never guess a reviewer that could equal the drafter.

## install.sh contract

`./install.sh detect | install <harness>|all [--project <dir>] [--ack-reviewed] | verify <harness> | uninstall <harness> | settings`

| Command | Target | Gate |
|---|---|---|
| `install mimo` | project `.mimocode/skills/research-agent/` + `~/.mimocode/skills/research-agent/` | runs now |
| `install opencode` | `~/.config/opencode/skills/research-agent/` | `--ack-reviewed` |
| `install claude` | plugin cache + `installed_plugins.json` v2 (`<name>@<marketplace>` entry, scope/installPath/version) + marketplace config — mirror the `rust-agent-builds` entry shape verbatim; README manual-install fallback | `--ack-reviewed` |
| `install codex` | `~/.codex/skills/research-agent/` (SKILL.md + CODEX.md overlay; AGENTS.md snippet appended) | `--ack-reviewed` |

`install all` without `--ack-reviewed` installs mimo and prints visible SKIP lines for the
rest. Idempotent; `--dry-run` prints the copy map; never touches `~/.agents/skills`.
